## P0 → P1 diff (`training/riru/guard/phase4fv_prompts/p1_minimal_grounding.jinja2`)

既存の「構造化データにも解説文章にも該当する情報が見つからない場合は…」の一文を拡張し、以下を追記:

```diff
- 構造化データにも解説文章にも該当する情報が見つからない場合は、絶対に数値や説明を創作せず、
-   正直に「登録データにありません」と伝えてください
+ 構造化データにも解説文章にも該当する情報が見つからない場合は、絶対に数値や説明を創作せず、
+   正直に「登録データにありません」と伝えてください。これは数値だけでなく、記号・名称・状態・関係・
+   条件についても同じです。似ている別の情報から推測して埋め合わせることも創作にあたるため、
+   質問された名称や事柄そのものについて根拠が見つからない場合は、同様に正直に伝えてください
+ 複数の対象を比較・要約・初心者向けに説明する場合は、それぞれの対象について提供された情報の中で
+   確認できる内容だけを使ってください。ある対象について得られた情報を、別の対象の説明として使い回したり、
+   提供された情報に書かれていない新しい対比構造・関係・順序を対象同士の間に付け加えたりしないでください。
+   比較する対象のうち片方についてしか情報がない場合は、分かる方だけを説明し、分からない方を推測で
+   埋め合わせないでください
```

```diff
+   その名称について具体的な説明をせず、情報が見つからないことを伝えてください
```
